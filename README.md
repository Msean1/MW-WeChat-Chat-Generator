# MW微信聊天器 V1.7

一款面向 Windows 的微信风格素材生成工具，可在本机制作聊天记录、朋友圈、群信息、红包和转账等演示画面。

软件完全离线运行。头像、图片、聊天内容和项目数据均保存在本机，不需要登录账号，也不会上传到服务器。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 聊天生成器 | 自定义聊天顶部名称、参与者、头像、发言顺序和聊天内容 |
| 消息类型 | 支持文字、图片、微信表情、红包、转账、语音、音视频、名片、拍一拍、撤回、系统提示和时间 |
| 微信表情 | 内置微信风格表情，可插入消息和聊天顶部名称 |
| 朋友圈生成器 | 制作朋友圈封面、图文内容、点赞和评论画面 |
| 支付与转账 | 制作收款结果、转账状态和账单详情画面 |
| 红包详情 | 制作红包卡片、领取结果和领取记录画面 |
| 个人资料 | 制作好友资料、个人资料和名片详情画面 |
| 群信息 | 自定义群成员、头像、群名称、群公告和展开、收起状态 |
| 项目管理 | 新建、保存、打开、复制项目，并保存为本机模板 |

## 图片与动图导出

- 普通 PNG 截图
- 完整聊天长图
- GIF 动图
- 逐帧 PNG 压缩包
- 1×、2×、3× 清晰度
- 自定义动图与逐帧间隔

导出文件会保存到系统下载目录。生成内容较多时，请等待进度完成后再关闭软件。

## 使用方法

1. 从 GitHub Releases 下载 `MW微信聊天器V1.7.exe`。
2. 双击运行。首次启动会准备本地运行组件，随后自动打开软件。
3. 设置聊天顶部名称并添加参与者。
4. 点击头像选择发言人，再选择消息类型并填写内容。
5. 在右侧手机预览中检查效果。
6. 点击“生成图片”“长截图”“GIF 动图”或“逐帧 PNG”导出素材。

## 项目保存

软件支持自动保存当前草稿，也可以手动保存项目文件。需要迁移到另一台电脑时，可使用“保存项目”导出 JSON，再通过“打开项目”恢复。

本机项目、模板和个人版数据相互独立。

## 运行环境

- Windows 10 或 Windows 11
- 64 位系统
- 建议预留至少 500MB 可用空间

## V1.7 更新内容

- 调整添加消息区域，消息类型保持单行显示。
- 发言人改为直接点击头像选择。
- 增加完整微信表情面板，修复表情排列问题。
- 聊天顶部名称改为独立设置，并支持插入微信表情。
- 优化群信息成员展开、收起及长文本显示。
- 修复消息无法添加和错误提示内容。
- 修复普通截图、长截图、GIF 和逐帧图片导出。
- 移除 WebM 视频导出。
- 清理个人素材，提供独立的同事使用版本。
